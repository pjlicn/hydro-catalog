# Hydrological Research Catalog

A curated guide to hydrological datasets, methods, software platforms, research challenges, and references.

## Website

**[Open the Hydrological Research Catalog](https://hydro-catalog.pages.dev/)**

The complete website is now hosted on Cloudflare Pages. The previous address,
<https://pjlicn.github.io/hydro-catalog/>, redirects to the new site.

## Suggest a resource or report a correction

Please [open a GitHub issue](https://github.com/pjlicn/hydro-catalog/issues/new) to:

- Suggest a dataset, method, software platform, benchmark, or reference guide.
- Report incorrect metadata, broken links, or missing citations.
- Propose improvements to the catalog.

For resource suggestions, include the resource name, official URL, a short explanation of its hydrological relevance,
and a primary reference when available. Please do not include credentials or private information.

## About this repository

This public repository provides the legacy website redirect and the issue tracker. It no longer distributes the
complete website source or catalog data. The website is maintained separately.

The public `main` branch is maintained as a single current snapshot rather than a development history.
The redirects retain recognized catalog page paths, query parameters, and URL fragments when JavaScript is enabled;
unrecognized old paths return to the new catalog homepage. A fallback homepage link is provided for other clients.
